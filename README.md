BMI Calculator 
 📌 Project Overview

The BMI Calculator is a data-driven project designed to calculate and analyse Body Mass Index (BMI) using individuals' height and weight. It provides insights into BMI patterns through data cleaning, analysis, visualisation, and an interactive Power BI dashboard.

The project aims to make BMI-related information easier to understand through simple calculations and meaningful visual representations.

🎯 Objectives

- Calculate BMI using height and weight.
- Clean and preprocess the BMI dataset.
- Perform exploratory data analysis.
- Identify patterns and trends in BMI data.
- Create meaningful data visualisations.
- Develop an interactive dashboard using Power BI.

Technologies Used

- **Python** – Data cleaning, analysis and visualisation.
- **Pandas** – Data manipulation and preprocessing.
- **Matplotlib / Plotly** – Data visualisation.
- **Power BI** – Interactive dashboard development.
- **Git and GitHub** – Version control and team collaboration.

📊 Project Workflow

1. Data Collection: Obtain the BMI dataset.
2. Data Cleaning: Identify and handle missing values, duplicate records and inconsistencies.
3. Data Analysis: Explore the dataset and calculate meaningful statistical insights.
4. Data Visualisation: Represent the findings using charts and graphs.
5. Dashboard Development: Build an interactive Power BI dashboard to present the results.

 📈 Expected Outcomes

- A cleaned and structured BMI dataset.
- Meaningful statistical insights from the dataset.
- Visual representations of BMI-related patterns.
- An interactive Power BI dashboard.
